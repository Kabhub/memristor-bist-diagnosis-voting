# Experimental provenance

Source manifests identify the evaluated RTL and runners. Raw reports, CSVs and
tool logs are preserved as recorded. Completed placement evidence is under
results/placement_sensitivity; placement/placement_audit.json records its checks.
Documentation identifying local pre-execution checks is explicitly marked
historical. No random-seed study, multiword prototype or ECP implementation is
represented by these records.

The evaluated_source_manifests/ directory preserves the original delivered
manifest for packets whose README documentation has since been updated.
RTL, testbench and runner hashes are unchanged. Recorded execution manifests
under results/ retain their original bytes. The experiment-folder manifest
describes the current packaged documentation and evaluated code.
